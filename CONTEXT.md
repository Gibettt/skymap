# Ephemeris Operations

Ephemeris coordinates resort-based astronomy experiences, bookings, and their financial outcomes.

## Language

**Resort Package**:
An independently managed experience offering belonging to exactly one resort, with its own availability, location, schedule, and prices.
_Avoid_: Global package, shared package

**Package Copy**:
A new Resort Package initially populated from another Resort Package and independently editable afterward.
_Avoid_: Linked package, synchronized package

**Free Package**:
A Resort Package with no positive adult or child price; its bookings produce no invoice, commission, or reward.
_Avoid_: Non-chargeable package

**Paid Package**:
A Resort Package with a positive adult or child price whose bookings participate in finance calculations.
_Avoid_: Chargeable package
